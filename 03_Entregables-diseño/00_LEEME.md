# Entregables de diseño

Aquí van los productos **generados a partir de la base de datos**: planes de sesión, casos, rúbricas y PPT de los cursos técnicos.

**No se escriben a mano.** La fuente de verdad es [`05_Base-de-datos/`](../05_Base-de-datos/00_LEEME.md); esta carpeta guarda lo que se produce desde ahí. Si al redactar un entregable detectas que el diseño está mal, se corrige en la base de datos y se vuelve a generar — no se parcha el documento.

Por poblar.
